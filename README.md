## 참고

- 앱 HTML은 각 Gemini 공유 링크의 Canvas 코드를 그대로 담았습니다. 외부 요청은 three.js·Tailwind·Google Fonts 같은 CDN 로드뿐이며 학생 정보를 입력받거나 저장하지 않습니다.
- 쇼릴 앱의 "Gemini 고음질 성우 합성"은 Gemini Canvas 안에서만 API 키가 주입되므로 이 사이트에서는 작동하지 않습니다(Gemini 원본 링크에서 사용).
